# React Job Cards

A simple ReactJS project that displays job openings using reusable components and props.

## Features

- Displays multiple job cards
- Reusable Card component
- Uses React props
- Company logo, job role, salary, and location
- Job tags
- Save and Apply Now buttons

## Technologies Used

- ReactJS
- JavaScript
- HTML
- CSS
- Vite
- Lucide React

## How to Run

```bash
npm install
npm run dev
